# ぽんぽんタッチ

赤ちゃん（0〜3歳）とペット（猫・犬）のためのタッチ遊びアプリ。本体は app.html（index.html は常に最新版を開くための入口）。1つの HTML ファイルで動作し、音はすべて Web Audio で合成しています（外部の音声ファイルなし・広告なし）。

## モード
- タッチであそぼ / うんち・おなら / いないいないばあ / どうぶつピアノ / もしもし / おえかき
- しろくろ（新生児向け）/ ねんねの音（こもりうた・胎内音・なきやみ音、タイマー付き）
- ねこモード / いぬモード

遊びモードは左上ボタンの長押し、またはタップ→「もどる」で終了します。
